# Embassey AI HQ — handoff to Claude Code

## How to use this pack

1. Unzip this folder into your project root (or an empty folder for a new project) as `design/`.
2. Open Claude Code in that project folder.
3. Paste the prompt from `CLAUDE_CODE_PROMPT.md`.

## What's inside

| File | Purpose |
|---|---|
| `CLAUDE_CODE_PROMPT.md` | The prompt to paste into Claude Code. |
| `PROJECT_BRIEF.md` | The full master instructions: stack, features, database, milestones and rules. |
| `DESIGN_SPEC.md` | The approved design: colour and type tokens, layout, the three screens, 3D scene layout, components and states. |
| `design-source/*.dc.html` | Source of the three design artboards. They are reference only: they need the Claude Design runtime to render, so read them for exact values instead of running them. |
| `references/*.png` | The three original inspiration screenshots. |

## The three screens

- **Main**: the HQ overview, with seven rooms around the Brain and a chat with Ada (Chief of Staff) on the left.
- **Office**: the Marketing department up close, with a team chat on the left and Zara's employee panel on the right.
- **Chat**: a voice chat with Kai (Software Developer), with live captions over his room.
